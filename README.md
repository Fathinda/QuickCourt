# 🏀 QuickCourt Mobile (Practice Project)

A simple sports venue booking application built with **Flutter**. This project is created for learning purposes and to practice implementing basic mobile app features.

---

## 🛠️ Features (Ongoing)

- **Basic Booking**: Simple flow to browse and book sports courts.
- **User Roles**: Separate screens for regular users and venue owners.
- **Profile Management**: Basic user profile and data display.
- **Firebase Integration**: Using Firebase for simple authentication and data storage.
- **Simple UI**: Built using Flutter's basic widgets to understand layout structures.

---

## 🧪 Tech Stack

- **Framework**: [Flutter](https://flutter.dev)
- **Language**: Dart
- **Database**: Firebase (Firestore & Auth)
- **State Management**: Provider (Basic implementation)

---

## ⚙️ How to Run

1. **Clone the repo**
   ```bash
   git clone https://github.com/Fathinda/QuickCourt.git
   ```

2. **Get dependencies**
   ```bash
   flutter pub get
   ```

3. **Run on emulator/device**
   ```bash
   flutter run
   ```
