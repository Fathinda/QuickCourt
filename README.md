# 🏟️ QuickCourt Mobile

QuickCourt Mobile is a premium, high-performance sports venue booking platform built with **Flutter**. It provides a seamless experience for both sports enthusiasts to find and book courts, and venue owners to manage their facilities.

---

## ✨ Features

- **Premium UI/UX**: Modern design system featuring glassmorphism, smooth gradients, and micro-animations.
- **Smart Booking**: Effortless court selection and scheduling.
- **Venue Management**: Comprehensive dashboard for owners to manage bookings, promotions, and FnB menus.
- **FnB Integration**: Order food and beverages directly through the app.
- **Real-time Updates**: Powered by Firebase for instant notifications and status changes.
- **Auth System**: Secure login and signup for both Users and Venue Owners.

---

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev)
- **Language**: Dart
- **State Management**: Provider
- **Backend**: Firebase (Auth, Firestore, Storage)
- **Design Pattern**: Feature-driven Architecture

---

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (Latest stable version)
- Dart SDK
- Android Studio / VS Code with Flutter extension

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Fathinda/QuickCourt.git
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```
